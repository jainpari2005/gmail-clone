# gmail-clone
Gmail Clone

A Gmail Clone web application developed using the MERN stack.

Features

- User Authentication
- Compose and Send Emails
- Receive Emails
- Inbox and Sent Messages
- Notifications
- User-friendly Interface

Technologies Used

Frontend:

- React.js
- Redux
- Tailwind CSS

Backend:

- Node.js
- Express.js
- MongoDB

Project Structure

- "frontend/" – Frontend application
- "backend/" – Backend application

Installation and Setup

1. Clone the repository:
   "git clone https://github.com/jainpari2005/gmail-clone.git"

2. Install backend dependencies:
   "cd backend"
   "npm install"

3. Install frontend dependencies:
   "cd frontend"
   "npm install"

4. Configure your environment variables before running the application.

Project Description

This project allows registered users to exchange emails through a web application with authentication, inbox, sent messages, email composition, and notifications.
